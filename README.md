# 🌦️ Weather Forecast Dashboard

A real-time weather dashboard built using the **OpenWeatherMap REST API** that displays:
- Current weather conditions
- 24-hour hourly forecast
- 5-day weather forecast
- Dynamic UI themes based on weather & day/night
- Animated weather effects (rain, snow, clouds, sun)

-------------------------------------------

## 🚀 Features
- 🌍 Search weather by city name
- 🕒 Next 24-hour forecast
- 📅 5-day forecast
- 🎨 Dynamic background themes (sunny, night, rain, snow, thunder)
- ⭐ Save favorite cities (LocalStorage)
- 🇺🇸 Quick view for major US cities

---

## 🛠️ Tech Stack
- HTML5
- CSS3 (Animations & Gradients)
- JavaScript (ES6)
- OpenWeatherMap API
- LocalStorage
